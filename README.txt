GitHub Pages 적용 방법
1. 이 ZIP의 압축을 풉니다.
2. travel-packing-2 저장소의 최상위(root)에 아래 파일을 업로드하여 교체합니다.
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   README.txt
3. Commit changes를 누릅니다.
4. Pages 재배포 후 기존 주소를 새로고침합니다.
5. 예전 화면이 남으면 기존 홈 화면 앱을 삭제한 뒤 브라우저에서 다시 열어 재설치합니다.
