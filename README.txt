싱말연수 v9

변경 내용
- 앱 이름: 싱말연수
- 준비물: 연수 안내사항 서류, 세미정장, 메모지·노트 추가 / 수영복 삭제
- 일정: 제목·시간·장소·메모 수정, 위/아래 순서 이동, 지도 링크, 하루별 색상 유지
- DAY별 방문 사진 업로드/삭제 추가 (사진은 해당 기기에 저장)
- 항공·호텔 예약 탭 삭제
- 환율 자동 계산: KRW / USD / SGD / MYR
- 자동 번역: 한국어 / 영어 / 말레이어
- 기존 싱가포르·말레이시아 아이콘 유지

GitHub Pages 적용
1. 이 폴더의 파일 7개를 기존 저장소 최상위(root)에 업로드합니다.
2. 같은 이름 파일은 교체하고 Commit changes 합니다.
3. Pages가 다시 배포된 뒤 기존 주소를 새로고침합니다.
4. 홈 화면의 이름/아이콘이 예전이면 기존 홈 화면 앱을 삭제한 뒤 다시 설치하세요.

참고
- 환율과 번역은 인터넷 연결이 필요합니다.
- 사진은 브라우저/앱의 기기 저장공간에 보관되며 브라우저 데이터 삭제 시 사라질 수 있습니다.
